# Snow Route 5W — Beta 1 (from-scratch rebuild)

The MapLibre-native rebuild of the Route 5W snow tracker, written from scratch
against the full feature checklist of the production app. The prototype's
approved look (integrated vector basemap, Metro palette, r41 paint) is the
visual foundation; all app code is new. Storage keys and backup formats are
identical to production, so progress and backups carry over.

Live: https://pleiades93.github.io/snow-route-5w-beta1/
Production app (untouched): https://pleiades93.github.io/snow-route-5w-tracker/
